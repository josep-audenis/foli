# @folijs/mcp

An MCP server for [Foli](https://github.com/josep-audenis/foli): the model of an MCP client
reads and edits `.docx` files through tools, every edit a tracked change in Word's sense, for a
person to accept or reject. Built on `@folijs/agent`.

> **In development (roadmap, Phase 14), not released.** Today it is the protocol and one tool,
> `read`. How it is meant to work: [ADR-0009](../../docs/decisions/ADR-0009-mcp-server.md).
