Word's Layout dialog for a selected picture or text box (More Layout Options…, 33.4): Position
(alignment or absolute position and what it is from, move with text, allow overlap, layout in
table cell) and Text Wrapping (style, sides, distance from text), applied in one undo step by
core's new `setObjectFloat`.
