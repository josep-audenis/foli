Text formatting (23.4): `formatText(handle, format, { on?, all? })` sets bold, italic, underline, strike, font, size, color, highlight and links on a paragraph or text in it, as tracked changes; `read({ formatting: true })` shows each paragraph's own run formatting (`Block.formatting`). The `format_text` tool, `read`'s `formatting` argument and `doc.formatText` in code mode. Table operations of several edits are all or nothing, and act on the row named in a vertically merged table.
