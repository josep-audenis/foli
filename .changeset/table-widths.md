Autofit tables widen a column for content that cannot break (a long word, a picture), as Word
does, keeping Word's saved widths otherwise; fixed tables keep their grid. The Table menu has
Column width… (`"columnWidth"` dialog) to set the selection's column width from the keyboard;
core's `columnAt(state)` gives that column. New toolbar strings: "Column width…", "Column width",
"Column width (cm)", "Enter a width in cm from 0.26 to 55.88.".
