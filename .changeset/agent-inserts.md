Inserting (23.6): `insertItem(handle, item, { where? })` inserts a picture (bytes, alt text, size read from PNG, JPEG or GIF and fitted to the page), a page or section break, a horizontal line, a footnote or an endnote, as tracked insertions; `imageInfo(bytes)`; the `insert` tool and `doc.insert`. `agentTools(session, host)` takes a `ToolHost` whose `picture(path)` gives the tools an image's bytes.
