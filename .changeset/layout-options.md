Layout Options (33.4): core's `setObjectWrap`, `setObjectMovesWithText`, `setObjectPosition`
(Word's nine presets), `setObjectLayout` (the Layout dialog's values), `selectedObject`,
`objectWrap`, `objectPosition`, `objectMovesWithText` for pictures and text boxes; the view's
`objectPlacement` (`storyView.objectPlacement`) keeps an object where it is drawn when its
layout changes, and a selected text box is outlined. React: the Wrap Text and Position menus
(Layout ▸ Arrange, Picture Format ▸ Arrange) and `FoliLayoutOptions`, Word's button beside a
selected picture or text box (on by default in `FoliEditor`, `layoutOptions={false}` hides it).
