Picture Format as Word's (33.6): Arrange (Position, Wrap Text, Bring Forward and Send Backward
with Word's entries, Align, rotate) and Size (Crop, Height and Width boxes, Size…), and a Shape
Format tab for a selected text box. Core's `setObjectOrder` (a float's `zOrder`, schema 10, written
as `relativeHeight`; floats drawn in that order) and `alignObject`.
