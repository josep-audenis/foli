# Example: the editor

`FoliEditor` from `@folijs/react` with its default toolbar, on A5 pages so the text visibly flows
from one page to the next. Type in it: everything below runs the packages' own code, from their
source on `main` (not a release from npm), and nothing of the site's. How to set it up in an app: [Getting started](../../../../docs/getting-started.md).
